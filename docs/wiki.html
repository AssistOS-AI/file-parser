These terms describe the project's own components and contracts.

process_documents

The MCP tool and command-line entry point convert one document to Markdown. The descriptor in file-parser-agent/mcp-config.json launches src/tools/process-documents.mjs. The command calls the document loader and formatter, reports warnings on standard error, and does not call the optional LLM helper.

Workspace path

A document path names a file visible to the process. The loader selects a nonempty options.workspaceRoot, then WORKSPACE_PATH, then the process working directory as its base. The command does not supply options.workspaceRoot, so its relative input uses the environment variable before the working directory. Absolute input stays absolute. The resolver normalizes separators but does not confine access to one directory.

Document record

The loader returns an internal record containing the resolved path, type, file metadata, summary, and extracted content or tables. The Markdown formatter uses that record to build human-readable sections and sampled table rows. This internal structure is not the command output schema.
