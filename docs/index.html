Document conversion

The process_documents command accepts one file path, reads the document, and writes Markdown to standard output. It includes document metadata, text previews, and sampled spreadsheet rows. Warnings go to standard error. The command does not invoke the optional structured-extraction helper.

Supported inputs

The loader accepts PDF, Word .doc and .docx, Excel .xls and .xlsx, and text files including .txt, .text, .log, and .md. A type hint identifies files without a useful extension. The caller must make the file readable in the agent runtime.

Repository boundaries

The implementation belongs to file-parser-agent/. Other top-level directories in the workspace are independently versioned projects. Their runtime, deployment, and data-ownership contracts belong to their own documentation.

Coding style defines source layout and the verification commands. Wiki contains the canonical project terms.
